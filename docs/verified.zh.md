# AIVN 自行验证结果

本页是“发现”中所有 **✓ 已验证** 和 **⚠ 未通过 AIVN 测试** 标签的出处。**ⓘ 按开发者** 标签则直接链接到模型卡或官方文档，并附原文引用。

约定：

- 只记录 AIVN 亲自运行过的测试。每项结果都来自某台特定电脑上的一次测试，使用的是精选目录中标明的量化文件，并不保证在所有电脑上都能得到相同结果。
- 测试电脑：Linux x64，8 线程 Intel Xeon CPU，15 GB 内存，**无 GPU**（llama.cpp 在 CPU 上运行）。有 GPU 的电脑会快得多；这里的耗时仅用于在模型之间相互比较。
- 本页没有条目的模型尚未经过 AIVN 验证；其标签（如有）仅代表开发者的说法。
- 未通过的测试同样会记录在案，以免有人把开发者的说法误认为已经过验证。

## 0.15.3 — AIVN AGENT 完成多步任务

主模型 **Qwen3 4B Instruct 2507**（Q4_K_M），无 GPU 的电脑，上下文长度 8192。

- **多步文件任务：** 读取 `chi-tieu-thang-9.csv`，计算总额、平均值和支出最多的类别，然后写入 `bao-cao-chi-tieu.md`（4 个工具步骤，数据正确）。
- **删除文件：** 文件无法移到回收站时，AIVN AGENT 会停下来询问用户，而不是自行永久删除。
- **记忆：** 保存了“Sinh viên VLU tên Khôi, thích môn học Trí tuệ nhân tạo.”（“VLU 学生，名叫 Khôi，喜欢人工智能这门课。”），并在之后的对话中再次用到。
- **定时任务：** 创建了喝水提醒，提醒按时运行。
- **API 服务器：** 为 `get_weather` 工具返回符合 OpenAI 标准的 `tool_calls`。
- **屏幕控制（以 Qwen3-VL 2B Q8_0 作为“眼睛”）：** 在模拟的 Zalo 上执行任务“Trong cửa sổ Zalo đang mở, tìm liên hệ Trần Quỳnh Anh và mở cuộc trò chuyện với người đó.”（“在已打开的 Zalo 窗口中，找到联系人 Trần Quỳnh Anh 并打开与其的对话。”）。AIVN AGENT 查看屏幕，在搜索框中输入姓名，没有找到结果时改为输入不带声调符号的写法，然后点击了正确的“Tran Quynh Anh”（4 步，289 秒）。
- 所有回答和报告都使用越南语。

AIVN Bench 窗口截图，包含 10 个项目（按钮、输入框、复选框、标签页、列表项）。逐一询问模型每个项目的坐标；返回的点落在该项目的边框内即为通过。测试电脑：Linux，8 线程 CPU，无 GPU（通过 llama-server 运行）。每个模型都使用其开发者公布的提示词格式和输出格式。

|---|---|---|
| UI-TARS-1.5 7B（界面智能体） | 9/10 | 171 秒 |

## 0.16 beta.2 — 用真实指令调用工具（2B / 4B / 8B）

在真机上出错（Zalo、Outlook 网页版、音量）之后重新测试。每条指令运行 5 次（温度 0.7），通过 llama-server `--jinja` 运行，并提供 AIVN AGENT 的全部工具定义；第一次调用就选对工具且参数正确，才算通过。

| 指令 | Qwen3-VL 2B Q8_0 | Qwen3-VL 4B Q4_K_M | Qwen3-VL 8B Q4_K_M |
|---|---|---|---|
| 在 Zalo 群组 `AIVN test` 中发送：`AIVN test 1` | 3/5 | 5/5 | 5/5 |
| 在 Outlook 网页版上撰写邮件，只撰写不发送（第一步） | 5/5 | 5/5 | 5/5 |
| 调高音量 | 5/5 | 5/5 | 5/5 |
| 把音量调到 100（设定音量） | 0/5 | 5/5 | 5/5 |
| Outlook 第 2 步：在元素列表中点击“新邮件”（“Thư mới”） | 0/5 | 5/5 | 5/5 |
| **合计** | **13/25** | **25/25** | **25/25** |

AIVN AGENT 的通过门槛：23/25。结论：
- Qwen3-VL 2B 已从 AIVN AGENT 的模型选择器中移除（仍可用于对话）。主要错误：再次调用 `open_app`，而不是点击已经看到的按钮；以及调用 `volume_up` 时附带音量值，而不是设定音量（AIVN 现在会自动改为设定音量，但第 2 步的错误仍然存在）。
- 12 GB 显存的电脑：默认使用运行流畅且通过本测试的最强模型（Qwen3-VL 8B）。
- 4 GB 显卡的笔记本电脑：Qwen3-VL 4B（需要溢出到内存时可能显示“运行较慢”）。
